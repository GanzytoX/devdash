# DevDash competition demo — 2 to 3 minutes

1. Open the public `/status` page and establish the problem: teams need a status page and monitoring without a large observability stack.
2. Point out the visible “Hosted on CubePath” identity and the real deployment URL.
3. Sign in and show the CubePath VPS uptime, CPU, RAM and disk values.
4. Open Services and run a real manual check.
5. Stop the controlled demo service to create an outage.
6. Show the incident, public status change and delivered Discord or Slack alert.
7. Restart the service and show recovery plus incident duration.
8. Export incidents as CSV and show the 7-day timeline.
9. Close with the one-VPS architecture, SQLite persistence and public repository.

Keep a prerecorded version of the same flow as a network-failure fallback.
