# Cubethon submission checklist

## Required

- [ ] Live CubePath URL works from an incognito browser.
- [ ] Project clearly says “Hosted on CubePath”.
- [ ] GitHub repository is public and contains no `.env` or database.
- [ ] Participation issue is registered before July 26, 2026.
- [ ] Demo remains running during evaluation.

## Hall of Fame assets

- One-sentence description: “DevDash is a lightweight, self-hosted uptime monitor and public status page that runs on a single CubePath VPS.”
- Technologies: React, TypeScript, Vite, Tailwind CSS, Express, Prisma, SQLite, Docker and Nginx.
- Capture: dashboard overview, public status page, incident recovery and CubePath system diagnostics.
- Record a 60–90 second GIF/video plus the full 2–3 minute demo.

## Final-day checks

- [ ] Reboot the VPS and verify automatic recovery.
- [ ] Confirm HTTPS expiration and DNS.
- [ ] Test login rate limiting and invalid credentials.
- [ ] Trigger and recover a controlled incident.
- [ ] Confirm Slack/Discord delivery.
- [ ] Download and verify the latest SQLite backup.
- [ ] Tag the submitted commit and avoid feature changes afterward.
